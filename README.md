# 🌐 IoT Device Monitoring Dashboard

A real-time IoT monitoring simulator with Flask and Dash. The system generates simulated sensor data (temperature & humidity) and visualizes it in a live dashboard. Built to demonstrate skills in full-stack development, data visualization, and real-time API integration.

## 🚀 Live Demo

- 🔗 Dashboard: https://iot-dashboard-3zs6.onrender.com
- 🔗 API Endpoint: https://iot-dashboard-simulator.onrender.com/iot-data

## 🔧 Tech Stack

- **Frontend**: Dash (Plotly), Pandas
- **Backend**: Flask, Flask-CORS
- **Data**: Simulated sensor data in JSON
- **Deployment**: Render (Free tier)

## 📊 Features

- Real-time data updates every 3 seconds
- Visual alerts for high temperature (>30°C) and high humidity (>60%)
- Deployed as two independent web services (frontend + backend)
- Fully responsive and easy to extend
